    Actions awaiting human approval

    The agent executes only auto-routed actions. Everything here was recommended with its route stated and is waiting on a person. A decision writes an APPROVED_BY edge onto the case — including a rejection, which is the most useful signal the memory layer gets.

    Measured likelihood ratios

    Every closed investigation replayed through the same extractor the agent uses, under its own as_of. These are measured from outcomes, not chosen.

    Compiled policy

    The bank's fraud policy as executable rules. The agent may only choose from the actions these rules permit; anything else is dropped before it reaches an answer file.
