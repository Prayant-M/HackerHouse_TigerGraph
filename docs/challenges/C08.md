# C08 — Analyst in the loop

**Depth:** medium

`POST /api/feedback/{case}` (bearer token) accepts or rejects a finding. A rejection on a card suppresses that finding on later cases of the same card; a signal rejected on two or more cases more than it is accepted has its reliability shrunk (never below 0.3). No model is retrained. Every answer lists `feedback_applied` with the feedback ids that caused each adjustment. `eval/feedback_round.py` runs one round on the October holdout: analyst decisions on 1–15 October, behaviour measured on 16–31 October.

**Attested:** When behaviour changes, the answer records which analyst decisions caused it (`caused_by`).

**Numbers:** `eval/reports/feedback_round.md` (generated by the run, never typed here).

**Reproduce:** `make feedback`
