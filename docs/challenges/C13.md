# C13 — Someone else's schema

**Depth:** rehearsed

`ingest/schema_mapper.py` maps an unseen CSV onto the canonical schema from three independent kinds of evidence per column pair — name tokens (camelCase/snake_case split, abbreviation and synonym expansion), type shape, and value overlap / quantile match with scale search — and detects reshapes (amount in cents, timestamp split into date + time, epochs, split card ids). Each mapping choice carries its score, its reasons and sample values from both sides. Rehearsed on a renamed + reshaped variant of our own data.

**Attested:** Each mapping choice comes with the sample records that justify it.

**Numbers:** `eval/reports/schema_mapping_rehearsal.json` (generated by the run, never typed here).

**Reproduce:** `python ingest/schema_mapper.py --rehearse`
