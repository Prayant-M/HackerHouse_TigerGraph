# C06 — Regulator's view

**Depth:** byproduct (recorded I/O + proof)

The examiner opens on the **Proof** tab: the minimal facts, the flip set, the precedent counts, and a *Recompute* button per fact that rebuilds the decision without it (served from the recording, no graph or model needed). The **Regulator replay** tab lists every tool call the agent made with its parameters, latency and the SHA-256 of what came back, a preview of the stored response, and a *Re-run* button that repeats the call against the live graph and says whether it still matches. The decision ledger is hash-chained; `make replay` reproduces the decision bit-for-bit offline.

**Attested:** Each step shows the evidence the agent actually had at that moment: the stored response, by content hash.

**Numbers:** console Proof + Regulator replay tabs; `.cache/recordings/<case>/` (generated by the run, never typed here).

**Reproduce:** `make replay CASE=<id>`
