# C11 — Data quality detective

**Depth:** medium (Innovation 4)

Dataset-level gaps (identity coverage, empty billing regions, placeholder emails, placeholder device strings, thin cards) with counts and sample ids, and per investigation the gaps that blind evidence *that* decision could have used (`core/quality.py`), re-checked against the graph with the installed `data_gaps` query. A tainted case cannot be called fraud with a block: taint widens the conformal set to {fraud, legit}, which routes to uncertain + ESCALATE_TO_ANALYST under R8.

**Attested:** Each problem lists the affected record ids and the investigations it taints.

**Numbers:** `eval/reports/data_quality.md` (generated by the run, never typed here).

**Reproduce:** `make quality`
