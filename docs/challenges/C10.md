# C10 — Break the agent

**Depth:** deep (Innovation 3)

Three attack families, each reproducible:

1. **Hostile text** — 40 injection templates (fake system text, role claims, approval claims, demands for both the right and the wrong outcome, JSON/field injection, homoglyphs, zero-width characters, delimiter breaks, GSQL/tool injection, analyst-note instructions) × every case, run on the recorded tool I/O (`eval/metamorphic.py` M2). Defence: the decision core cannot read free text; a deterministic extractor reads only allow-listed facts and flags instruction-like spans; the LLM sees text only inside a delimited data block. Compared with a naive LLM that reads the text and decides (`eval/naive_llm_baseline.py`).
2. **Activity shaped to look innocent** — evasion-frontier attacks read off our own thresholds (3 legs, $430 legs, a 90-minute burst, a diluted burst, $6 probes), planted as `ATK-*` transactions; defence: relative rules (`FRONTIER_HARDENING`), re-backtested for legitimate hits; plus frontier mining of confirmed fraud that sat just past the old boundary.
3. **Signals built to mislead** — R7 seasoning (a fresh card seasoned with small recurring charges) is detected and reported.

**Attested:** Every attack is a test case with the ids of the data planted (`ATK-*`) or the template name and case id.

**Numbers:** `eval/reports/metamorphic.md`, `attacks.md`, `naive_llm_baseline.md` (generated by the run, never typed here).

**Reproduce:** `make metamorphic && make attacks`
