# C02 — Self-growing detective

**Depth:** medium

`eval/detectors.py` mines conjunctions of measured facts that are ≥ 95% confirmed fraud with support ≥ 25 on July–September, preferring conjunctions that cut across documented patterns (low dominant-pattern share) and touch few controls. Each becomes a declarative detector spec (`type: facts`), is backtested on October (caught / missed / legitimate touched, with ids), and is filed in `data/detectors/registry.json` as **proposed**. It joins the toolkit only when a fraud manager approves it: `POST /api/detectors/{id}` with a bearer token; the server checks the role, signs the decision into the approval ledger and writes a `Detector` vertex through `governance_write`. Approved detectors run in every investigation (evidence only).

**Attested:** Every proposed detector ships with its backtest: what it caught, what it missed, which legitimate customers it would have acted against.

**Numbers:** `eval/reports/detectors.md` (C2 table), `data/detectors/registry.json` (generated by the run, never typed here).

**Reproduce:** `make detectors`
