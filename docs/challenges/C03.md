# C03 — Policy text to detector

**Depth:** medium

R5 and R6 are compiled from the prose in `data/policy/chunks.jsonl` — every number (three authorisations, one hour, $100) is read from the clause text by `compile_policy()`, not typed — into executable specs, run over every replayed closed case, and compared with the agent's own judgement: agreements, disagreements, and the fraud rate of the cases only the rule flags, each with case ids.

**Attested:** The detector's backtest and every agreement / disagreement with the agent, with ids.

**Numbers:** `eval/reports/detectors.md` (C3), `detectors.json` (`rule_only`, `agent_only`) (generated by the run, never typed here).

**Reproduce:** `make detectors`
